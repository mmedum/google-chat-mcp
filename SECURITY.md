# Security policy

## Reporting a vulnerability

Report it privately, through **GitHub's private vulnerability reporting**
on this repository: the Security tab, then "Report a vulnerability". Do
not open a public issue. If you cannot use private reporting, open a
minimal public issue asking for a private channel, and a maintainer will
follow up.

Include the impact, how to reproduce it, and the version
(`google-chat-mcp --version`, a release tag or a commit).

## Supported version

Only the most recent release receives fixes. A fix ships as a release of
its own.

## Response

We acknowledge a report within **5 business days** and coordinate the
disclosure with you. No bug bounty is offered.

[`docs/security.md`](docs/security.md) is the threat model. It says what
counts as a vulnerability here and what does not.
